# GSC Devboard Remote Tast Tests (`gscdevboard`)

Package `gscdevboard` contains remote Tast integration tests that validate
Google Security Chip (GSC) firmware (Ti50 and Cr50) on development boards
and host emulation via the `devboardsvc` gRPC harness.

## Documentation

All documentation for GSC devboard architecture, fixtures, helpers, runtime
variables, `make tast` execution, container workflows, and board recovery is
consolidated in `platform/ti50/common/docs/gsc_devboard_tast.md`.
